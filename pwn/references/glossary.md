# Glosarium

| Istilah | Arti dalam latihan |
| --- | --- |
| ABI | Kesepakatan biner tentang register, tipe, stack dan pemanggilan |
| Alignment | Syarat kelipatan alamat, misalnya untuk stack sebelum call |
| Core | Snapshot memori dan register yang dapat dianalisis sesudah proses berhenti |
| Endian | Urutan byte suatu nilai multibyte di memori atau protokol |
| Frame | Konteks satu pemanggilan fungsi yang dapat ditelusuri debugger |
| Inferior | Proses yang dikendalikan GDB |
| Lifetime | Rentang waktu ketika objek C masih ada dan dapat diakses secara sah |
| Ownership | Perjanjian tentang pihak yang bertanggung jawab melepas sumber daya |
| Relokasi | Penyesuaian rujukan alamat oleh linker atau loader |
| Section / segment | Pengelompokan isi untuk toolchain / deskripsi bagian yang relevan saat pemuatan |
| Source / sink | Asal data / operasi yang menggunakannya |
| Tube | Antarmuka pwntools untuk kirim-terima byte |
| Xref | Referensi dari lokasi instruksi atau data ke lokasi lain |
